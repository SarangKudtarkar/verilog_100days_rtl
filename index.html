Getting started

How to use this lab

01 · Pick an example

Browse all 45 designs. Open the RTL or testbench directly on GitHub, or load both into the playground.

02 · Edit and simulate

The playground loads the design and testbench. Edit either pane and press its Run/Simulate control to compile and execute in your browser.

03 · Run the full suite

For the complete, authoritative regression—including full SVA support—clone the repository and run ./run.sh with Verilator 5 or later.
