How the repo is organized

Design. Verify. Iterate.

Each implemented day follows the same small, repeatable structure.

01 / RTL

Design source

RTL modules live in src/, named by day and design topic, for example day05_rca_4bit.sv.

02 / TESTBENCH

Self-checking verification

Matching testbenches live in tb/. Shared helpers are in include/tb_utils.svh.

03 / SIMULATE

One runner, multiple simulators

run.sh lists examples, runs one day or the full suite, and can launch waveform-enabled runs.

04 / ASSERT

Check behavior, not just compilation

SystemVerilog assertions and testbench checks help verify functional behavior across the examples.

# List implemented examples

Simulator note: The README recommends Verilator 5 or newer for the complete suite. Icarus Verilog is supported with some SystemVerilog assertion features disabled; the README reports that 34 of the 45 examples compile under Icarus. Questa/ModelSim, VCS, Xcelium and Vivado xsim are also listed as supported simulator options. GTKWave can be used to inspect generated waveforms.
